# Legacy Settings

This directory contains the previous APPLaunch Settings page implementation,
its Settings-specific models, and the tests that exercised that UI.

The archived sources are intentionally outside the active `main/ui` source
tree. The new Settings UI can be integrated under `main/ui/page_app` without
the legacy implementation being compiled or registered.

Shared models that are still used by other applications remain in the active
source tree.
